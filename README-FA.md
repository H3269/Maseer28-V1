# Maseer28 — نسخه React/Vite

این نسخه روی تجربه کاربر نهایی متمرکز است. کتابخانه فقط برای انتخاب و مطالعه چهار کتاب استفاده می‌شود و بخش مدیریت/آپلود کتاب از رابط و کد اجرایی حذف شده است.

## اجرا

```bash
npm install
npm run dev
```

## Build نهایی

```bash
npm run build
```

خروجی در پوشه `dist` ساخته می‌شود و روی وب‌سرور Static، Nginx، IIS، Vercel یا سرویس مشابه قابل انتشار است.

## ساختار اصلی

- `src/App.jsx` — جریان اصلی برنامه و سیاست بازگشت به خانه پس از اجرای مجدد
- `src/features/journey/` — State و منطق مسیر ۲۸ روزه
- `src/features/library/LibraryPage.jsx` — کتابخانه کاربر
- `src/features/library/Reader.jsx` — رابط کتاب‌خوان
- `src/features/library/readerEngine.js` — صفحه‌بندی، تیترها، فصل‌ها و جدول‌ها
- `public/content/path-content.json` — محتوای مسیر ۲۸ روزه
- `public/content/library.seed.json` — فهرست اولیه کتاب‌ها
- `public/content/books/` — محتوای چهار کتاب
- `public/assets/covers/` — جلدها
- `src/styles/original-v72.css` — استایل برنامه و کتاب‌خوان

## رفتار کتاب‌خوان در این نسخه

- هر فصل/بخش اصلی یک صفحه عنوان مستقل دارد و متن آن از صفحه بعد ادامه پیدا می‌کند.
- تیترهای داخل فصل از متن عادی متمایز و درشت‌تر/بولد نمایش داده می‌شوند.
- تیتر در انتهای صفحه تنها نمی‌ماند و همراه چند خط بعدی جابه‌جا می‌شود.
- بخش‌های «بخش عملی کتاب» و «ضمائم کتاب» در جلد سوم به‌صورت مستقل در فهرست و متن قرار گرفته‌اند.
- جدول‌های جلد سوم و کتابچه تکمیلی به‌صورت جدول واقعی، قابل اسکرول افقی، نمایش داده می‌شوند.
- در ابتدا/انتهای کتاب دیگر پنجره خطای «پایان کتاب» نشان داده نمی‌شود؛ فلش همان سمت غیرفعال می‌شود.
- محل مطالعه هر کتاب جداگانه ذخیره می‌شود. بعد از اجرای مجدد برنامه، کاربرِ تکمیل‌شده وارد صفحه خانه می‌شود و با باز کردن دوباره همان کتاب، مطالعه از محل قبلی ادامه پیدا می‌کند.
- منطق اولین اجرای برنامه (کپی‌رایت، تشکیل پرونده و مراحل اولیه) بدون تغییر حفظ شده است.

## داده کتاب‌ها

محتوای کتاب‌ها از فایل‌های JSON داخل `public/content/books/` خوانده می‌شود. داده هر کتاب می‌تواند `pages`، `blocks`، `chapters` و جدول‌ها را در خود نگه دارد. Reader برای نسخه‌های قدیمی‌تر که اطلاعات قالب‌بندی کمتری دارند نیز تیترهای قابل تشخیص را از فهرست و ساختار متن بازیابی می‌کند.

### قرارداد صفحه‌آرایی V81
در V81 تغییرات کتاب‌خوان صرفاً ساختاری و بصری‌اند. متن کتاب‌ها بازنویسی نمی‌شود. در فهرست مطالب، «بخش / فصل / زیرعنوان» سلسله‌مراتب مستقل دارند و گروه فصل تا حد ظرفیت صفحه کنار هم نگه داشته می‌شود. عنوان اصلی فصل نیز در صفحه‌ی آغاز فصل با مرتبه‌ی بصری بزرگ‌تر نمایش داده می‌شود.

### یادداشت V82 — صفحه‌آرایی تمرین‌ها
در کتاب‌خوان، تمرین‌های عملیِ شماره‌دار و واحدهای کاربرگ/تمرین جامع به‌عنوان بخش مستقل صفحه‌آرایی می‌شوند. این تغییر فقط روی شکست صفحه و سلسله‌مراتب بصری اثر دارد؛ متن، جمله‌ها، واژه‌ها و ترتیب محتوای کتاب بازنویسی نمی‌شوند.

### نکته نسخه V83
پس از اینکه کاربر برای نخستین بار ثبت پرونده، تنظیم مسیر و ارزیابی اولیه را کامل کرد، نوار ناوبری پایین در تمام بخش‌های برنامه ثابت می‌ماند. در onboarding اولین ورود، این نوار عمداً نمایش داده نمی‌شود.


### تغییر V84
در جلد سوم، صفحه تصویری ارسالی نویسنده بلافاصله پس از جلد اصلی و پیش از متن کتاب نمایش داده می‌شود. فایل تصویر در `public/assets/reader/book3-opening-page.png` قرار دارد.

### تغییر V85 — ساختار فهرست، تیترها و جدول‌ها
نسخه V85 ساختار جلد سوم را دقیقاً به سه واحد مجزا در انتهای متن اصلی تفکیک می‌کند: فصل چهاردهم، بخش عملی/مسیر ۲۸ روزه، و ضمائم. زیرعنوان‌های داخل فصل‌ها در هر چهار جلد با مرتبه بصری مستقل نمایش داده می‌شوند. جدول‌های واقعی جلد سوم و جلد تکمیلی حفظ و به صورت قابل پیمایش نمایش داده می‌شوند. همچنین Seed کتابخانه دارای revision شده است تا نصب‌های قبلی نیز محتوای جدید را دریافت کنند و روی نسخه قدیمی IndexedDB باقی نمانند. متن کتاب‌ها در این فرایند بازنویسی نمی‌شود.

### نکته نسخه V86
منوی اصلی پایین برنامه عمداً داخل کتاب‌خوان نمایش داده نمی‌شود؛ در حالت مطالعه فقط کنترل‌های اختصاصی Reader دیده می‌شوند. در سایر صفحات برنامه، پس از تکمیل ورود اولیه، منوی اصلی پایین همچنان فعال است.
