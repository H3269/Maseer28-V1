# T16 — افکار منفی و نشخوار فکری
## پیش‌نویس بازطراحی ۲۸ روزه | B2-BF
**وضعیت:** پیش‌نویس برای بازبینی؛ نه تأیید تخصصی و نه محتوای فعال اپ.

**دامنه:** فکر ناخوشایند به‌تنهایی واقعیت یا قصد عمل نیست. هدف حذف اجباری افکار نیست؛ بلکه تشخیص الگو، فاصله گرفتن از درگیری تکراری و بازگشت انعطاف‌پذیر به زندگی روزمره است.
