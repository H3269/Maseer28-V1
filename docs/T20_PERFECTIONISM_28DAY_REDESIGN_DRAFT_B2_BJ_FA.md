# T20 — کمال‌گرایی
## پیش‌نویس بازطراحی ۲۸ روزه | B2-BJ
**وضعیت:** پیش‌نویس برای بازبینی؛ تأیید تخصصی نشده است.
**دامنه:** کاهش استانداردهای خشک و بازبینی افراطی، تقویت معیار «به‌اندازه کافی خوب» و حفظ کیفیت متناسب با اهمیت کار.
