# T25 — رنجش و کینه
## پیش‌نویس بازطراحی ۲۸ روزه | B2-AX | فارسی

**وضعیت:** پیش‌نویس برای بازبینی؛ تأیید تخصصی و ممیزی یکتایی سراسری انجام نشده است.

### جهت‌گیری اختصاصی
بررسی آسیب و نیاز برآورده‌نشده، انتخاب گفت‌وگو یا فاصله؛ بخشش اجباری یا آشتی با فرد آسیب‌زننده هدف نیست.

### قواعد استفاده
- روزانه یک تمرین کوتاه؛ زمان و شدت قابل کاهش است.
- هدف، افزایش انتخاب آگاهانه است نه حذف فوری احساس یا کنترل دیگران.
- نسخه سبک، توقف یا ثبت‌نکردن تجربه مجاز است.
