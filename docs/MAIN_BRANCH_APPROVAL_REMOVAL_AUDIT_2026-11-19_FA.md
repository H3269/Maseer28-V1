## یافته‌های قطعی

### F-01 — گیت تأیید متخصص هنوز در workflow انتشار وجود دارد (بحرانی)

فایل `.github/workflows/publish-tested-version.yml` هنوز مرحله زیر را اجرا می‌کند:

- `Require expert approval for all daily content`
- فرمان: `npm run assert:production-content`

اما در `package.json` هیچ script با نام `assert:production-content` تعریف نشده است. بنابراین اگر اجرای workflow به این مرحله برسد، فرمان npm با خطای script ناشناخته متوقف می‌شود. این همان وابستگی انتشار به تأیید متخصص است که باید حذف/جایگزین شود؛ نه اینکه با حذف ساده آن، کنترل‌های ساخت و ایمنی هم حذف شوند.

### F-02 — workflow اعتبارسنجی موردنیاز انتشار در شاخه وجود ندارد (بحرانی)

در همان workflow، مرحله `Require successful validation for this exact commit` اجرای workflow با مسیر `validate-content.yml` را برای SHA دقیق `main` جست‌وجو می‌کند و خروجی را به `scripts/assert-validation-run.mjs` می‌دهد.

در درخت کامل فعلی `.github/workflows/` فقط این دو فایل وجود دارند:

- `deploy.yml`
- `publish-tested-version.yml`

فایل `validate-content.yml` وجود ندارد. اسکریپت `assert-validation-run.mjs` نیز در صورت نبود اجرای موفق برای SHA دقیق، انتشار را متوقف می‌کند. بنابراین مسیر انتشار فعلی پیش‌نیاز اعتبارسنجی‌ای را مطالبه می‌کند که در این شاخه تعریف نشده است.

### F-03 — آزمون انتشار با workflow فعلی تناقض مستقیم دارد (بحرانی)

در `tests/assistantReleaseGate.test.js` آزمونی با عنوان `production publication does not depend on review metadata` وجود دارد که صریحاً انتظار دارد متن `assert:production-content` در workflow انتشار وجود نداشته باشد.

اما همان عبارت و مرحله در `.github/workflows/publish-tested-version.yml` فعلی وجود دارد. پس این assertion در اجرای آزمون، با محتوای فعلی فایل ناسازگار است و باید شکست بخورد. این نتیجه از مقایسه مستقیم دو فایل به دست آمده؛ **اجرای واقعی آزمون هنوز انجام نشده است**.

### F-04 — UI دستیار به metadata تأیید دسترسی می‌زند که Gateway برنمی‌گرداند (بالا)

- `src/features/assistant/AssessmentAssistant.jsx` در نمایش نتیجه دانش، `item.approval.reviewer_role`، `item.approval.review_record_id` و `item.approval.version` را می‌خواند.

این یک وابستگی پنهان و ناسازگاری قرارداد UI/Gateway است. نمایش attribution بازبین باید از UI حذف یا با قرارداد واقعی منبع/شواهد جایگزین شود.

### F-05 — workflow محیط آزمایش تست‌های رگرسیون را اجرا نمی‌کند (بالا)

`.github/workflows/deploy.yml` فقط `npm ci` و build آزمایشی Vite را اجرا می‌کند و سپس GitHub Pages را deploy می‌کند. در این workflow فرمان `npm test`، اعتبارسنجی محتوا، ممیزی وابستگی یا آزمون مرورگر اجرا نمی‌شود.

- `knowledgeGateway.js` و schema دانش: اعتبارسنجی ساختار، منبع و قواعد ایمنی مستقل از reviewer/approval است؛ این مسیر باید حفظ شود.
