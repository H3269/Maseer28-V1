- `Require expert approval for all daily content`
- فرمان: `npm run assert:production-content`

اما در `package.json` هیچ script با نام `assert:production-content` تعریف نشده است. بنابراین اگر اجرای workflow به این مرحله برسد، فرمان npm با خطای script ناشناخته متوقف می‌شود. این همان وابستگی انتشار به تأیید متخصص است که باید حذف/جایگزین شود؛ نه اینکه با حذف ساده آن، کنترل‌های ساخت و ایمنی هم حذف شوند.

در درخت کامل فعلی `.github/workflows/` فقط این دو فایل وجود دارند:

- `deploy.yml`

فایل `validate-content.yml` وجود ندارد. اسکریپت `assert-validation-run.mjs` نیز در صورت نبود اجرای موفق برای SHA دقیق، انتشار را متوقف می‌کند. بنابراین مسیر انتشار فعلی پیش‌نیاز اعتبارسنجی‌ای را مطالبه می‌کند که در این شاخه تعریف نشده است.
