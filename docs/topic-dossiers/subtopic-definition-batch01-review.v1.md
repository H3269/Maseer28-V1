## گیت عبور
بسته اول فقط پس از تکمیل منبع‌سنجی، بازبینی روان‌شناس/روان‌درمانگر و بررسی ایمنی محصول می‌تواند برای انتقال کنترل‌شده به رجیستری canonical پیشنهاد شود. تا آن زمان همه ۱۸ تعریف خارج از runtime می‌مانند.
