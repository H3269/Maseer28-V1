- ۲۸ راهنمای روزانه × ۱۴ پرسش = **۳۹۲ پاسخ آماده**.

- هر ۳۹۲ پاسخ از نظر متن عیناً متمایزند؛ q08 نیز برای هر روز پاسخ مستقل دارد.
- پاسخ آماده فقط با شناسه canonical موضوع/روز و تطبیق دقیق تمرین و اقدام همان روز ارائه می‌شود. هویت اشتباه یا متن نامنطبق، پاسخ آماده نمی‌گیرد.
- fallback عمومی یا پاسخ آزاد جدید برای T12 اضافه نشده است؛ ماژول prepared-only باقی می‌ماند.
