# نتیجه ممیزی وابستگی‌های npm

**تاریخ:** 2026-11-01  
**شاخه:** `planning/assistant-foundation-v1`  
**روش:** اجرای `npm audit --audit-level=high` در GitHub Actions پس از `npm ci`

## نتیجه

ممیزی npm در وضعیت فعلی ناموفق شد و این وضعیت باید پیش از انتشار عمومی تعیین تکلیف شود:

- ۳ آسیب‌پذیری گزارش شد: ۲ مورد با شدت High و ۱ مورد با شدت Moderate.
- گزارش، `source-map-js 1.0.0–1.2.1` را با شدت High علامت‌گذاری کرد (GHSA-68fv-2mgg-jv7q) و اعلام کرد `npm audit fix` برای آن در دسترس است.
- زنجیره `vite <= 6.4.3` و `esbuild <= 0.24.2` نیز در گزارش به‌عنوان آسیب‌پذیر با شدت Moderate آمده است (GHSA-67mh-4wv8-2f99).
- نسخه‌های قفل‌شده در package-lock بررسی‌شده: Vite 5.4.21، esbuild 0.21.5 و source-map-js 1.2.1.

## تصمیم ایمن پیشنهادی

1. ارتقای patch/minor سازگار برای `source-map-js` از مسیر lockfile و اجرای مجدد audit و build.
2. برای رفع زنجیره Vite/esbuild، برنامه ارتقای جداگانه Vite با بررسی سازگاری plugin-react، تنظیمات Vite، خروجی PWA و مسیرهای build تهیه شود.
3. از اجرای کورکورانه `npm audit fix --force` خودداری شود؛ گزارش npm پیشنهاد می‌کند این فرمان Vite 8.3.5 را نصب کند که تغییر major و پرریسک برای این پروژه است.
4. تا زمان رفع یا پذیرش رسمی ریسک‌ها، نتیجه audit باید در PR و تصمیم انتشار قابل مشاهده بماند.

## محدودیت

این گزارش بر اساس advisoryهای registry در زمان اجرای workflow است. exploitability در محیط واقعی یا امکان دسترسی مهاجم از طریق dev server به‌صورت پویا آزموده نشده است. ریسک esbuild عمدتاً به dev server و شرایط اجرای آن وابسته است؛ نباید بدون تحلیل deployment به‌عنوان آسیب‌پذیری قطعی نسخه production توصیف شود.


## ۲. نتیجه رفع و راستی‌آزمایی (2026-11-01)

در شاخه توسعه، به‌جای `npm audit fix --force`، Vite به خط پشتیبانی‌شده `6.4.5` ارتقا یافت. نسخه `@vitejs/plugin-react 4.7.0` با Vite 6 سازگار است (peer range آن شامل `^6.0.0` است).

قفل وابستگی با npm از روی `package.json` بازتولید شد؛ سپس `npm ci` و آزمون‌ها روی همان lockfile اجرا شدند. نسخه‌های نهایی:
- Vite: `6.4.5`
- esbuild: `0.25.12` (رفع GHSA-67mh-4wv8-2f99؛ نسخه اصلاح‌شده advisory از 0.25.0 به بعد است)
- source-map-js: `1.2.2` (رفع GHSA-68fv-2mgg-jv7q)

**نتیجه CI نهایی، run شماره ۲۷:**
- نصب پاک `npm ci`: موفق
- `npm audit --audit-level=high`: موفق؛ `found 0 vulnerabilities`
- اعتبارسنجی محتوا: موفق؛ ۳۴ موضوع، ۹۵۲ روز، ۹۵۲ شناسه یکتا و ۴۴۲ ارجاع کتاب معتبر
- build تولیدی: موفق؛ Vite 6.4.5، تعداد ۴۱ ماژول تبدیل‌شده

بنابراین دو advisory ثبت‌شده در ممیزی قبلی در شاخه این PR رفع شده‌اند و audit در lockfile نهایی هیچ آسیب‌پذیری شناخته‌شده‌ای گزارش نمی‌کند. این نتیجه، تضمین نبود هر نوع آسیب‌پذیری یا جایگزین آزمون امنیتی پویا نیست.
