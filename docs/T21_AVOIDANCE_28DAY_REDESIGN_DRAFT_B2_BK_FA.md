# T21 — اجتناب
## پیش‌نویس بازطراحی ۲۸ روزه | B2-BK
**وضعیت:** پیش‌نویس برای بازبینی؛ تأیید تخصصی نشده است.
**دامنه:** شناخت چرخه اجتناب و افزایش اقدام تدریجی در موقعیت‌های امن و متناسب. دوری از خطر واقعی، مرزبندی و استراحت ضروری «اجتناب ناسازگار» محسوب نمی‌شود.
