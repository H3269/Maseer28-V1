# T30 — شک و تردید
## پیش‌نویس بازطراحی ۲۸ روزه | B2-BT
**وضعیت:** پیش‌نویس برای بازبینی؛ تأیید تخصصی نشده است.
**دامنه:** تصمیم‌گیری متناسب با اهمیت، جمع‌آوری اطلاعات کافی و تحمل عدم قطعیت؛ نه حذف کامل تردید.
