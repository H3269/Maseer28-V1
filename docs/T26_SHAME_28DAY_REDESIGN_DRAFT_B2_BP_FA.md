# T26 — شرم
## پیش‌نویس بازطراحی ۲۸ روزه | B2-BP
**وضعیت:** پیش‌نویس برای بازبینی؛ تأیید تخصصی نشده است.
**دامنه:** تمایز شرم از مسئولیت رفتاری، کاهش پنهان‌کاری فرساینده و تقویت حریم خصوصی و خودشفقتی. افشاگری اجباری یا نمایش آسیب‌پذیری هدف نیست.

**تمرین:** موقعیتی را که شرم را فعال کرد، بدون افشای جزئیات غیرضروری ثبت کنید.
**نسخه سبک:** یک جمله درباره تجربه یا مرز شخصی ثبت کنید.
**معیار بازتاب:** آیا شرم را تجربه‌ای قابل مشاهده دیدید، نه تعریف نهایی هویت؟
