# گزارش‌ساز ارزیابی فهم موضوعی — نسخه آزمایشی

## هدف
این ابزار خط پایه فعلیِ تطبیق عبارت‌محور را روی مجموعه مصنوعی فارسی اجرا می‌کند و خطاها را در سطح هر سناریو و هر موضوع آشکار می‌سازد. هدف، پنهان‌نکردن ضعف‌ها پشت یک میانگین کلی و فراهم‌کردن نقطه شروع برای ارزیابی‌های بعدی است.

## اجرا
`npm run evaluate:semantic`

خروجی JSON شامل precision، recall، F1، تطابق دقیق مجموعه موضوعات، خطاهای هر سناریو، جزئیات هر موضوع و یک بررسی واژگانی محدود برای سناریوهای علامت‌گذاری‌شده ایمنی است.

## محدودیت‌های غیرقابل‌چشم‌پوشی
- مجموعه فعلی ۲۰ سناریوی مصنوعی است و benchmark معتبر یا نمونه نماینده کاربران نیست.
- موتور فعلی تطبیق عبارت‌هاست، نه فهم معنایی واقعی.
- سناریوهای دارای اولویت ایمنی از امتیازدهی موضوعی کنار گذاشته می‌شوند. بررسی واژگانی آن‌ها فقط نشان می‌دهد چند عبارت از پیش تعریف‌شده دیده شده‌اند؛ عدم کشف عبارت به معنی ایمن‌بودن نیست و این سنجه حساسیت بالینی یا توان تشخیص بحران نیست.
- برای سناریوهای موضوعی، پاسخ منفی ثابت فقط یک ابزار کنترل‌شده برای رسیدن به مرحله دسته‌بندی است و هیچ نتیجه‌ای درباره ایمنی کاربر نمی‌دهد.
- برای عبور از مرحله آزمایشی، باید داده فارسی متنوع و دارای رضایت، برچسب‌گذاری مستقل، داوری اختلاف، آزمون adversarial و پروتکل تخصصی ایمنی فراهم شود.
- هیچ عددی در این گزارش مجوز اتصال مدل، توصیه درمانی یا فعال‌سازی عمومی دستیار نیست.

## معیارهای لازم برای مرحله بعد
1. گسترش داده به نمونه‌های واقعیِ بی‌هویت و دارای رضایت، با پوشش گونه‌های زبانی و موقعیت‌های متنوع.
2. ارزیابی جداگانه هر یک از ۳۴ موضوع و نقش اصلی/همراه/نامشخص.
3. اندازه‌گیری نفی، نقل‌قول، طعنه، چندمعنایی، اصلاح کاربر و abstention.
4. بازبینی تخصصی مستقل برای هر مسیر ایمنی؛ شکست در یک سناریوی پرخطر نباید با میانگین کلی پوشانده شود.
5. تعیین معیارهای پذیرش توسط متخصصان واجد صلاحیت، نه انتخاب دلخواه تیم فنی.
