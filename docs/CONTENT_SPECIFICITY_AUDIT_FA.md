# ممیزی اختصاصی‌بودن محتوای ۲۸ روزه

## اجرا
`npm run audit:content-specificity`

گزارش برای هر فیلد و هر روز تعداد نسخه‌های متنی متمایز و روزهایی را که متن پس از جایگزینی نام موضوع بین مسیرها یکسان است نشان می‌دهد.

## محدودیت
متفاوت‌بودن متن به‌تنهایی تناسب روان‌شناختی یا اعتبار علمی را اثبات نمی‌کند؛ شباهت معنایی نیز با مقایسه رشته‌ای قابل رد یا تأیید قطعی نیست. این ابزار فقط هشدار بازبینی می‌دهد و هیچ محتوایی را خودکار بازنویسی نمی‌کند.

## سیاست پذیرش
هر تمرین باید از نظر هدف رفتاری، سازوکار هدف، تناسب با موضوع/زیرموضوع، دشواری، خطر و احتیاط، معیار توقف و شاخص پیشرفت ارزیابی شود. تنوع ظاهری متن معیار پذیرش نیست.
