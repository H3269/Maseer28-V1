# فضای کاری موقت بسته‌های T06 تا T34

این پوشه محل نگهداری بسته‌های تکمیل‌شده موضوعات T06 تا T34 در جریان پروژه «گسترش مسیر ۲۸» است.

## ساختار
برای هر موضوع، یک زیرپوشه مستقل با شناسه همان موضوع ایجاد می‌شود:
- T06/
- T07/
- …
- T34/

هر زیرپوشه فقط پس از آماده‌شدن واقعی فایل‌های همان بسته ایجاد و با محتوای تکمیل‌شده پر می‌شود. فایل نمونه، placeholder یا محتوای تأییدنشده به‌عنوان بسته تکمیل‌شده ثبت نمی‌شود.

## قواعد نگهداری
- الگوی ساختاری و معیارهای پذیرش تثبیت‌شده در پروژه و دفتر ثبت وقایع مرجع هستند.
- سؤال‌های آماده مشترک بین موضوع‌ها و روزها ثابت می‌مانند؛ پاسخ‌ها باید برای هر موضوع و هر روز اختصاصی باشند.
- هر بسته شامل مسیر ۲۸ روزه و راهنمای دستیار روزمحور مطابق قرارداد پروژه است.
- ثبت یک بسته در این پوشه به‌معنای تأیید تخصصی مالک، اجرای آزمون، ادغام یا انتشار نیست.
- تا دستور جداگانه مالک، هیچ ادغام نهایی یا انتشار عمومی انجام نمی‌شود.
- این پوشه موقت است و پس از تکمیل کل پروژه و ادغام نهایی، طبق دستور پروژه حذف خواهد شد.

## وضعیت اولیه
این پوشه ایجاد شده است؛ هنوز هیچ‌یک از بسته‌های T06 تا T34 در این مسیر به‌عنوان بسته تکمیل‌شده ثبت نشده‌اند.
