## 4. یافته‌های مهم برای چرخه جاری

1. **شکاف runtime:** پیش‌نویس کامل‌تر وجود دارد اما محتوای اجرایی همچنان دو فیلدی است. تا تعیین منبع canonical و قرارداد داده، نباید صرفاً با کپی‌کردن متن پیش‌نویس، آمادگی runtime اعلام شود.
2. **نگاشت زیرموضوع:** جدول روزانه B2-ZS پیشنهاد است. روزهای ۱، ۷، ۱۹ و ۲۶ نیازمند بازبینی بر اساس خروجی واقعی روز (شروع در برابر تکمیل/تحویل) هستند.
3. **توالی مداخله:** روز ۱۴ باید از دستور مبهم «کاهش یک‌درجه‌ای رفتار» فاصله بگیرد و به اصطکاک مشخص و قابل مشاهده وصل شود. روز ۱۷ باید بازگشت بدون شرم پس از وقفه را حفظ کند. روز ۲۰ باید پایش اختیاری و تکلیف‌محور باشد، نه امتیاز شخصیتی/تشخیصی. روز ۲۴ باید به وابستگی، واگذاری، توافق یا روشن‌سازی مسئولیت مربوط باشد.
4. **تفاوت علت‌ها:** مسیر باید به‌جای فرض علت واحد، شروع/تکمیل، وضوح، اولویت، منابع، ظرفیت، اجتناب هیجانی و موانع اجرایی/ساختاری را از هم جدا کند.
5. **شواهد و بازبینی:** اسناد قبلی منابع علمی مرتبط را فهرست کرده‌اند، اما منبع‌دهی claim-level برای هر روز و ثبت reviewer واقعی/تاریخ/شناسه بازبینی کامل نیست. هیچ روزی نباید بدون مدرک به `reviewed` یا `approved` ارتقا یابد.
6. **تکرار:** نتیجه غربال عینی قبلی باید بازتولید و روی نسخه نهایی runtime تکرار شود؛ صفر تکرار عینی به‌تنهایی نبود تکرار مفهومی را ثابت نمی‌کند.
