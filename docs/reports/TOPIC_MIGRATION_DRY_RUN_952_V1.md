# گزارش Dry Run مهاجرت طبقه‌بندی ۹۵۲ روزه مسیر۲۸

- نسخه: 1.0.0
- وضعیت: شبیه‌سازی فقط‌خواندنی؛ مهاجرت اجرا نشده است
- شاخه بررسی‌شده: `feature/topic-taxonomy-audit-v1`

## خلاصه نتیجه

| سنجه | نتیجه |
|---|---:|
| دسته‌های قدیمی | ۳۴ |
| محتوای روزانه قدیمی | ۹۵۲ |
| رکوردهای صف مهاجرت | ۹۵۲ |
| رکوردهای نامزد نگاشت ساختاری | ۹۵۲ |
| رکوردهای دارای خطای تطبیق در این dry-run | ۰ |
| پیش‌نویس‌های بازطراحی‌شده | ۱۰۲ |
| رکوردهای بدون پیش‌نویس | ۸۵۰ |
| رکوردهای صف دارای subtopic_id | ۰ |
| رکوردهای runtime eligible | ۰ |

تمام ۳۴ نام دسته قدیمی با alias دقیق فارسی و شناسه موضوع متناظر تطبیق داشتند. برای هر ۹۵۲ رکورد، شناسه محتوای مبدأ در فایل محتوای قدیمی پیدا شد؛ نام دسته و شماره روز نیز با صف یکسان بود. شناسه‌های موضوع معتبر بودند و در ۱۰۲ مورد دارای پیش‌نویس، شناسه پیش‌نویس و زیرموضوع با موضوع و روز متناظر سازگار بود.

## توزیع پیش‌نویس‌ها

۱۰۲ پیش‌نویس فقط برای روزهای ۱ تا ۳ هر یک از ۳۴ موضوع وجود دارد. روزهای ۴ تا ۲۸ برای هر موضوع هنوز پیش‌نویس بازطراحی‌شده ندارند؛ یعنی ۲۵ روز × ۳۴ موضوع = ۸۵۰ رکورد.

## حفظ ارجاعات کتاب

در ۴۴۲ رکورد محتوای قدیمی ارجاع کتاب وجود دارد. توزیع ارجاع‌ها بر اساس bookId:

- bookId 1: ۳۴
- bookId 2: ۳۴
- bookId 3: ۱۰۲
- bookId 4: ۱۷۰
- bookId 5: ۱۰۲

در این dry-run هیچ ارجاعی حذف یا بازنویسی نشده است. حفظ این ارجاع‌ها باید invariant مهاجرت آینده باشد.

## اثر مستقیم پیشنهادهای تغییر زیرموضوع

سه پیشنهاد زیرموضوعی فعلی هر کدام یک پیش‌نویس را تحت تأثیر قرار می‌دهند:

| شناسه مبدأ | پیش‌نویس متأثر | تصمیم فعلی | وضعیت |
|---|---|---|---|
| T04-S02 | `DRAFT_T04_D02` (روز ۲ موضوع نفرت) | پیشنهاد انتقال به T18 | نیازمند بازبینی محتوایی؛ تصویب نشده |
| T15-S03 | `DRAFT_T15_D03` (روز ۳ اعتمادبه‌نفس پایین) | پیشنهاد انتقال به T23 | نیازمند بازبینی محتوایی؛ تصویب نشده |
| T18-S03 | `DRAFT_T18_D03` (روز ۳ نفرت از خود) | بدون مقصد | مسدود تا تأیید طراحی ایمنی |

این سه پیش‌نویس همگی همچنان `draft_pending_expert_review` و `runtime_eligible=false` هستند. این اثرها باید پیش از هر مهاجرت محتوایی به‌صورت موردی بررسی شوند؛ تغییر شناسه به‌تنهایی کافی نیست.

## محدودیت‌ها و موارد حل‌نشده

1. تطبیق ۹۵۲ رکورد فقط در سطح دسته/موضوع و شناسه مبدأ انجام شده است؛ اثبات هم‌ارزی محتوایی یا بالینی نیست.
2. صف ۹۵۲تایی فاقد `subtopic_id` است؛ بنابراین ۸۵۰ رکورد فاقد نگاشت زیرموضوعی‌اند و ۱۰۲ پیش‌نویس موجود نیز هنوز در صف با شناسه زیرموضوع ثبت نشده‌اند.
3. رجیستری موضوع و زیرموضوع هنوز تعریف‌های تخصصی، scope notes و شواهد کافی ندارد؛ این dry-run کیفیت علمی را تأیید نمی‌کند.
4. نگاشت‌های T04-S02 و T15-S03 همچنان پیشنهادهای نیازمند بازبینی محتوا هستند؛ این شبیه‌سازی آنها را تصویب نکرده است.
5. T18-S03 بدون مقصد باقی می‌ماند تا safety registry مستقل طراحی و تأیید شود.
6. T14/T32، T06، T11 و دیگر تصمیم‌های مرزی taxonomy با تطبیق نام حل نمی‌شوند و باید در مرحله محتوایی بررسی شوند.

## تصمیم مهاجرت

**هیچ مهاجرتی مجاز نیست.** ۹۵۲ مورد را می‌توان از نظر ساختاری در گروه `candidate_mapped` قرار داد، اما هیچ‌کدام وضعیت approved ندارند. ۸۵۰ مورد نیازمند تولید/بازبینی پیش‌نویس، همه رکوردها نیازمند بازبینی محتوایی متناسب، و تمام مسیرها نیازمند گیت ایمنی و تأیید مالک هستند.

## بازتولید و کنترل تازگی گزارش

```bash
npm run dry-run:topic-migration -- --write
npm run validate:topic-migration-dry-run
```

گزارش JSON شامل نتیجه هر ۹۵۲ رکورد، طبقه‌بندی، پیشنهاد اقدام و Git blob SHA تمام ورودی‌هاست. اعتبارسنج، گزارش ذخیره‌شده را با محاسبه مجدد از فایل‌های فعلی مقایسه می‌کند تا کهنگی گزارش یا تغییر ناخواسته ورودی‌ها آشکار شود.
