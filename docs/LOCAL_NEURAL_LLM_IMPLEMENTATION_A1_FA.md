# نمونه اجرایی مدل زبانی عصبی محلی — A1

**وضعیت:** prototype کدنویسی‌شده در `main`؛ آزمون واقعی runtime و دستگاه هنوز باز است.  
**تاریخ:** 2026-11-08

## معماری

- Runtime: `@huggingface/transformers@4.3.2` با ONNX Runtime Web.
- Model: `onnx-community/Qwen3-0.6B-Instruct-ONNX`، revision ثابت `54250909aca286a05b9d013c8af7a21859ee6ead`، dtype برابر `q4f16`، اجرای `wasm` در Worker و یک thread.
- وزن مدل در مخزن یا bundle قرار نمی‌گیرد. دریافت اولیه فقط پس از فرمان صریح «بارگیری مدل محلی» شروع می‌شود؛ حجم فایل اصلی تقریباً 650 MB است و tokenizer/config نیز لازم‌اند.
- Cache مرورگر با Cache Storage و کلید نسخه‌دار نگهداری می‌شود. اجرای عادی فقط از cache محلی بارگذاری می‌کند. پس از آماده‌شدن مدل، `allowRemoteModels=false` می‌شود.
- فایل‌های WASM/اجرایی ONNX Runtime از `node_modules` به `public/ort` کپی می‌شوند و از همان مبدأ برنامه سرو می‌شوند؛ CDN برای runtime تنظیم نشده است.
- Worker هنگام نصب فقط GET فایل‌های revision ثابت مدل در Hugging Face را مجاز می‌کند؛ درخواست دارای body یا مسیر دیگر رد می‌شود. پس از بارگذاری، درخواست خارجی مسدود است. متن پرسش در URL/body مدل قرار نمی‌گیرد.
- ورودی مدل فقط پرسش فعلی و زمینه/شواهد بازیابی‌شده محلی است. اطلاعات پروفایل، پزشکی و dailyContext به مدل داده نمی‌شوند.
- مسیر روزانه، safety handoff، scope clarification، personal intake و نبود شواهد معتبر از تولید عصبی خارج هستند. UI تازه‌ای افزوده نشده؛ نصب و پیشرفت در همان چت موجود نمایش داده می‌شود.

## محدودیت‌ها

1. Qwen3-0.6B کوچک است؛ پشتیبانی زبانی مدل پایه تضمین‌کننده کیفیت فارسی این checkpoint نیست.
2. وزن حدود 650 MB است؛ RAM اوج و سرعت WASM روی Android 11/دستگاه کم‌منبع هنوز اندازه‌گیری نشده است.
3. Cache Storage و WASM باید در Telegram WebView و Bale WebView واقعی آزموده شوند؛ Chrome به‌تنهایی کافی نیست.
4. این prototype مجوز پاسخ آزاد درباره موضوعات شخصی/درمانی ایجاد نمی‌کند و گیت P3 را دور نمی‌زند.
5. CI یا unit tests جایگزین بارگیری واقعی، قطع اینترنت، network capture و آزمون دستگاه نیستند.

## معیار پذیرش

- pipeline واقعی ONNX generation را روی Worker و WASM اجرا کند.
- پس از نصب، قطع اینترنت مانع load/generation نشود.
- network capture نشان دهد prompt، transcript، متن کتاب یا داده شخصی به مقصد خارجی نرفته است.
- حجم دانلود، زمان بارگیری، زمان اولین توکن، tokens/sec، RAM اوج، پایداری پس‌زمینه و cache persistence در Telegram/Bale/Chrome ثبت شود.
- کیفیت فارسی با پرسش‌های واقعی و ارزیابی انسانی سنجیده شود؛ برای دستگاهی که توان اجرا ندارد، پشتیبانی ادعا نشود.
