# T25 — رنجش و کینه
## پیش‌نویس بازطراحی ۲۸ روزه | B2-BO
**وضعیت:** پیش‌نویس برای بازبینی؛ تأیید تخصصی نشده است.
**دامنه:** فهم اثر رنجش، روشن کردن نیاز و مرز، تصمیم درباره گفت‌وگو یا فاصله و کاهش درگیری ذهنی. بخشایش یا آشتی هدف اجباری نیست.
