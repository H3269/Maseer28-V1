# T31 — کنترل‌گری
## پیش‌نویس بازطراحی ۲۸ روزه | B2-BU
**وضعیت:** پیش‌نویس برای بازبینی؛ تأیید تخصصی نشده است.
**دامنه:** تشخیص رفتارهای کنترلی، شناخت نیاز پشت آن‌ها و جایگزینی فشار با درخواست، توافق و تحمل تفاوت. این مسیر کنترل لازم برای ایمنی واقعی را با کنترل‌گری رابطه‌ای یکی نمی‌داند.
