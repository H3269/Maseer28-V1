# هویت بصری آزمایشی مسیر ۲۸ — فیروزه و لاجورد

## ایده مرکزی
الهام از کاشی‌کاری ایرانی با برداشت امروزی و خلوت؛ ترکیب فیروزه‌ای، لاجوردی، آبی آسمانی و سفیدی روشن. هدف، ایجاد حس آرامش، اعتماد، امید و اصالت است؛ نه تبدیل رابط به یک سطح پرزرق‌وبرق یا شلوغ.

## قواعد استفاده
- فیروزه‌ای برای اقدام اصلی، نشانگر پیشرفت و جزئیات منتخب؛ نه پس‌زمینه تمام صفحه.
- سربرگ عمیق لاجوردی/سرمه‌ای با متن سفید برای خوانایی.
- دکمه فیروزه‌ای با متن سرمه‌ای تیره؛ از متن سفید روی فیروزه‌ای پرهیز شود.
- لاجوردی برای عناصر ساختاری، آیکون‌های مهم و حالت انتخاب‌شده.
- آبی آسمانی برای جزئیات ثانویه و نمودارها.
- سفید و زمینه‌های بسیار روشن، فضای غالب صفحات باقی بمانند.
- رنگ‌های معنایی موفقیت، هشدار و خطر مستقل بمانند و با رنگ برند جایگزین نشوند.
- نقوش الهام‌گرفته از کاشی‌کاری فقط در لوگو، تصویرسازی یا تزئینات محدود استفاده شوند؛ نه پشت متن‌های طولانی.

## دسترسی‌پذیری
- متن اصلی باید روی زمینه روشن با کنتراست بالا نمایش داده شود.
- دکمه فیروزه‌ای از متن سرمه‌ای استفاده کند.
- رنگ به‌تنهایی نباید وضعیت را منتقل کند؛ آیکون یا متن کمکی نیز لازم است.
- کنتراست اجزای تعاملی، حالت فوکوس، پیام‌ها و نمودارها باید در تست مرورگر بررسی شود.

## دامنه این تغییر آزمایشی
این راهنما و CSS فقط در شاخه `brand/iranian-turquoise-preview` اعمال شده‌اند. شاخه `main` و فرایند انتشار تلگرام/بله دست‌نخورده‌اند. لوگو و آیکون نصب برنامه هنوز بازطراحی نشده‌اند و باید پس از تأیید بصری، جداگانه بررسی شوند.
