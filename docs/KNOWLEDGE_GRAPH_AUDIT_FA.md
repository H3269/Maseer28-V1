# ممیزی ساختاری شبکه دانش مسیر۲۸

## دامنه و روش
این گزارش از چهار رجیستری نسخه ۱ در مخزن استخراج می‌شود: موضوعات، زیرموضوع‌ها، روابط کاندیدا و تعریف‌های کاری. اسکریپت فقط یکپارچگی شناسه‌ها و پیوندهای داخلی را بررسی می‌کند؛ داوری علمی یا بالینی انجام نمی‌دهد.

## یافته‌های خط پایه در main
- ۳۴ موضوع رسمی با شناسه‌های T01 تا T34
- ۳۴ تعریف کاری اولیه در وضعیت پیش‌نویس
- ۱۰۲ زیرموضوع پیشنهادی (سه مورد برای هر موضوع)
- ۴۰ رابطه کاندیدا از نوع possible_association
- همه روابط فاقد درجه شواهد، فاقد شناسه منبع و غیرفعال برای runtime هستند
- هیچ موضوعی هنوز پیوند مستند به شواهد، محتوای دوره یا مداخله ندارد

## تفسیر
ساختار اولیه منسجم است، اما شبکه دانش هنوز «دانش تأییدشده و قابل استفاده برای تصمیم‌گیری» نیست. روابط کاندیدا نباید برای استنتاج علت، اولویت‌بندی بالینی یا پیشنهاد مداخله استفاده شوند. تعریف‌ها نیز تا داوری متخصص و اتصال به منابع معتبر، پیش‌نویس باقی می‌مانند.

## گام‌های لازم برای تکمیل
1. ممیزی هر زیرموضوع و ثبت تعریف عملیاتی، مرز مفهومی و موارد افتراقی.
2. اتصال هر ادعای علمی به منبع قابل ردیابی، نوع مطالعه، جمعیت، محدودیت و تاریخ بازبینی.
3. تفکیک رابطه همبستگی، هم‌زمانی، هم‌پوشانی، تقدم زمانی و علیت؛ علیت بدون شواهد مناسب ممنوع.
4. نگاشت محتوای ۲۸روزه به موضوع/زیرموضوع فقط پس از بازبینی انسانی هر روز؛ نگاشت ماشینی بر اساس نام موضوع کافی نیست.
5. اتصال تمرین‌ها به هدف، جمعیت، منع/احتیاط، سطح شواهد و معیار توقف.
6. تأیید متخصص و آزمون مستقل پیش از هرگونه فعال‌سازی در runtime.

## اجرا
`npm run audit:knowledge-graph`

این گزارش عمداً «آماده برای runtime» را false نگه می‌دارد تا کامل‌بودن ساختار با اعتبار علمی اشتباه نشود.
