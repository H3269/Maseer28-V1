# کنترل رضایت محلی مسیر۲۸ — نسخه آزمایشی

## دامنه
این ماژول فقط انتخاب‌های رضایت را به‌صورت محلی ثبت می‌کند. هیچ متن گفتگو یا داده سلامت را ارسال نمی‌کند و به‌تنهایی هیچ سرویس ابری، حافظه بلندمدت یا تحلیل محصولی را فعال نمی‌کند.

## اصول اجرایی
- هر چهار هدف مستقل‌اند: پردازش ابری، داده حساس سلامت، حافظه بلندمدت و تحلیل محصول.
- پیش‌فرض همه هدف‌ها خاموش است.
- ثبت رضایت به اقدام صریح نیاز دارد؛ سکوت، ادامه استفاده یا فعال‌بودن یک هدف، رضایت هدف دیگر نیست.
- رضایت پردازش داده حساس علاوه بر رضایت ابری، اقدام جداگانه و توضیح دسته داده را می‌خواهد.
- پس‌گرفتن رضایت ابری، رضایت پردازش داده حساس را نیز خاموش می‌کند.
- رضایت حافظه و تحلیل مستقل از رضایت ابری باقی می‌ماند.
- پاک‌کردن رکورد رضایت، همه هدف‌ها را به حالت خاموش برمی‌گرداند.

## محدودیت‌ها و مانع انتشار
- این پیاده‌سازی localStorage است و در برابر دسترسی محلی دستگاه، پاک‌شدن داده مرورگر یا XSS محافظت رمزنگارانه فراهم نمی‌کند.
- رابط کاربری رضایت، اتصال به پردازشگر، کنترل واقعی نگهداری/حذف نزد ارائه‌دهنده، اثبات هویت پردازشگر و ارزیابی حقوقی هنوز پیاده‌سازی نشده‌اند.
- ماژول فعلاً در جریان runtime برای مجازکردن ارسال داده فراخوانی نمی‌شود؛ تا زمان تکمیل UI، بررسی امنیتی، حقوقی و آزمون end-to-end، پردازش ابری و حافظه بلندمدت باید خاموش بمانند.
- این ماژول به‌تنهایی رضایت حقوقی معتبر یا انطباق با GDPR/قوانین دیگر را اثبات نمی‌کند.
