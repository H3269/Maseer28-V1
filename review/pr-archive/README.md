# PR review archive

This directory contains immutable patch snapshots from selected open pull requests for later review. Nothing here is active application code. The branch was created from `main` at `c18e1d4543c33bc0e5efb30bdc85d4c2df0702a2`.

See `manifest.json` for the selected PR list and exclusions. Each `patches/PR-N.patch` is the unified diff captured from the original PR. Do not apply a patch without reviewing it against the current `main` and running the relevant tests.
